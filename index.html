Data sources, historical comparison and limitations

Source: open-matchday, a free community-hosted football CSV dataset updated daily. View methodology and sources. Current data is mirrored into this site every 6 hours by a scheduled GitHub Action, with GitHub's raw file service as a fallback. Historical domestic league CSVs are requested on demand from football-data.co.uk (with an archival GitHub fallback where available). No paid API key is required.

Goals: final home and away goals combined. Corners: home + away match corners. Shots / shots on target: league overview combines both teams; team explorer shows the named club's own attempts. Cards: yellow cards plus red cards, each counted as one card (not booking points). Won/conceded: corners for/against each club.

Denominators: averages for a metric use only completed matches where that metric is actually recorded. Missing values are excluded, not treated as zero. Game counts vary across leagues and clubs, especially for stats that arrive late.

Update cadence: the source dataset is rebuilt daily, though detailed shot and card fields can lag 1–2 gameweeks. This page retrieves the newest available published CSV every time it opens and when you press Refresh. This is not second-by-second in-play coverage.

Resilience: if a live request fails, leagues from the earlier three-league analysis may show an archived October 2026 reference; Bundesliga and Ligue 1 show unavailable data instead. The offline reference contains estimates from mixed sources and should not be treated as live or a verified comparison.

Usage: the community dataset is offered for informational/non-commercial use. Check the original data sources' terms before commercial redistribution or automated high-volume scraping. No betting predictions are generated.
